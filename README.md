# Türk Masalları

## Proje Hakkında
Türk Masalları, Türk kültürüne ait masalları okuyucularla buluşturmak amacıyla hazırlanmış bir web sitesi projesidir. Kullanıcılar farklı masalları keşfedebilir ve okuyabilir.

## Projenin Özellikleri
- Türk masallarını görüntüleme ve okuma
- Masallar arasında gezinme
- Masalları bulmayı kolaylaştıran etkileşimli özellikler
- Kullanıcı dostu arayüz ve tasarım
- HTML, CSS ve JavaScript ile hazırlanmış tek dosyalı web sitesi

## Nasıl Kullanılır?
1. `index.html` dosyasını bilgisayarınıza indirin.
2. Dosyayı Google Chrome veya başka bir internet tarayıcısında açın.
3. Web sitesini kullanmaya başlayın.

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript
